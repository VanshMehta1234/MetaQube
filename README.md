# METAQUBE

![METAQUBE Logo](./public/metaqube-logo.png)

## Overview

METAQUBE is a cutting-edge digital experience platform that transcends traditional digital spaces and accelerates innovation. Built with modern web technologies, METAQUBE offers a seamless blend of Web3 capabilities, metaverse experiences, and rich interactive UI.

## Features

- **Responsive Design**: Fully optimized for all device sizes from mobile to desktop
- **MetaMirror Mode**: Toggle between standard and immersive MetaMirror interfaces
- **Web3 Integration**: Seamless integration with blockchain technologies
- **Interactive Elements**: Animated UI components with fluid transitions
- **Dynamic Content**: Content that adapts based on user interactions
- **Easter Eggs**: Hidden interactive elements for users to discover

## Technology Stack

- **Frontend**: React with TypeScript
- **Styling**: TailwindCSS with custom theme
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Router**: React Router
- **State Management**: Zustand

## Installation

1. Clone the repository
   ```bash
   git clone <repository-url>
   cd metaqube
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Build for production
   ```bash
   npm run build
   ```

## Project Structure

```
/src
  /components
    /3d           # 3D visualization components
    /layout       # Main layout components (Navbar, etc.)
    /sections     # Page section components
    /ui           # Reusable UI components
  /hooks          # Custom React hooks
  /pages          # Top-level page components
  /store          # Zustand state management
  /types          # TypeScript type definitions
  /utils          # Utility functions
```

## UI Components

The project includes the following key UI components:

- **MetaMirrorToggle**: Toggle between standard and immersive modes
- **ToggleGroup**: Interactive project parameter toggles
- **HeroCube**: 3D cube animation for hero section
- **FrensMap**: Dynamic partner showcase with filtering
- **BuildYourQube**: Interactive product selection
- **Footer**: Site footer with Easter egg functionality

## Color Scheme

Custom color palette defined in the Tailwind configuration:

- **metaEmerald**: Primary brand color with accents
- **deepCosmos**: Dark color spectrum for backgrounds
- **quantumGrey**: Neutral color palette
- **prismWhite**: Pure white accents
